# Plume PDF v0.1.4

Patch release after the latest bug-fix merges.

## Fixes

- Fix AI chat Stop semantics so an active streaming transport is cancelled before a later queued turn.
- Fix stale async preparation/fallback errors after Stop, New Conversation, dispose, or latest-wins ownership transfer; cancelled work now resolves as stopped instead of leaking an obsolete error.

## Version

- App: `0.1.4+28`
- Windows MSIX: `0.1.4.0`

Release artifacts are produced by the existing Build Packages workflow for Linux, Windows, macOS, and Android arm64-v8a.
